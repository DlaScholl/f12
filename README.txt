APEX Engineering Lab — обновлённый сайт

1. Откройте index.html в современном браузере.
2. Не удаляйте файл f1-tyre.webp — он нужен для фотографии шины.
3. Для редактирования: стили находятся внутри тега <style>, интерактивность внутри <script>.
4. Если нужен один файл без дополнительных ресурсов, используйте «Формула-1_готовый_сайт.html», который находится отдельно от архива.

Интерактивные маркеры расположены внутри SVG с единым viewBox.
Разделы: Анатомия болида, Аэродинамика, Шины, О Формуле-1.
